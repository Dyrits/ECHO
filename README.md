# Echo

A simple social network front-end similar to X, built with Solid.js.

**Status:** work in progress (exploratory project)

## About The Project

Exploratory front-end project using Solid.js: a simple social network similar to X.

### Built With

- Solid.js (@solidjs/router, solid-icons)
- TypeScript
- Tailwind CSS
- Vite

## Getting Started

### Prerequisites

- Node.js and a package manager. Dependencies are maintained with pnpm, but any package manager works.

### Installation

```sh
pnpm install
```

## Usage

```sh
pnpm dev     # development server on http://localhost:3000
pnpm build   # production build in dist/
pnpm serve   # preview the production build
```

The `dist/` folder can be deployed to any static host.
